# Student Academic Risk Predictor

An end-to-end AI/ML application that predicts a student's **dropout and academic failure risk** using machine learning, with a professional Streamlit dashboard.

---

## 1. Project Title

**Student Academic Risk Predictor**

---

## 2. Problem Statement

Academic dropout is a costly problem for students, families, and institutions. Early identification of at-risk students enables targeted intervention — tutoring, counselling, financial support — before it is too late. However, manually reviewing every student's profile is impractical at scale.

---

## 3. Motivation

Colleges and universities lose significant revenue and human potential to preventable dropout. Predictive analytics can flag students who are sliding toward failure weeks before the end of a semester, giving advisors actionable, data-driven insights rather than relying solely on gut feeling or end-of-term grades.

---

## 4. Proposed Solution

A machine learning system that:
- Ingests academic and demographic features for any student
- Classifies each student as **Low / Medium / High** dropout risk
- Predicts their **expected GPA** for the current semester
- Provides a plain-English explanation of the key risk factors
- Stores all predictions in a local SQLite database for historical review

## 8. Dataset Generation Methodology

A synthetic dataset of **1,500 student records** is generated by `generate_dataset.py` using a latent **"student quality"** factor (sampled from a clipped normal distribution) that drives all academic behaviour features. This ensures realistic correlations:

- High quality → high attendance, high scores, few missed deadlines
- Part-time job → slight quality penalty
- Higher parent education → slight quality boost
- Noise is added to every feature to prevent perfect separability

The GPA target is computed from a weighted formula of midterm score, assignment score, attendance, study hours, missed deadlines, and previous GPA (when available). The risk level is derived from a composite risk score of GPA, attendance, and missed deadlines.

A fixed seed (`SEED=42`) guarantees full reproducibility.

## 10. ML Methodology

### Classification (Risk Level)
1. Load and preprocess data
2. Median imputation for missing numerics; mode for categoricals
3. Standard scaling of all numeric features
4. One-hot encoding of categorical features
5. 80/20 stratified train/test split
6. 5-fold cross-validation on the training set
7. Train three models and compare on the held-out test set
8. Select the best by macro F1-score

### Regression (GPA)
1. Same preprocessing pipeline (shared preprocessor artifact)
2. Train two regressors, select by R²

## 12. Evaluation Metrics

- **Accuracy** — overall fraction correct
- **Precision / Recall / F1 (macro)** — class-balanced classification quality
- **ROC-AUC** — discrimination ability across all thresholds
- **MAE** — mean absolute GPA prediction error
- **RMSE** — penalises large GPA errors more heavily
- **R²** — proportion of GPA variance explained by the model

## 17. Example Usage

**Single prediction via the UI:**
1. Open the app (`python run.py`)
2. Navigate to **Single Student Prediction** in the sidebar
3. Set: Attendance=40%, Midterm Score=30, Missed Deadlines=7, Study Hours=3/week
4. Click **Predict Risk**
5. Result: **HIGH RISK** badge, GPA ~1.2, probability chart, and explanation

1. Download the CSV template from the **Batch Prediction** page
2. Fill in student records and upload
3. Download predictions with color-coded risk levels

## 18. Limitations

- The model is trained on **synthetic data** — real-world performance will differ until retrained on actual institutional records
- The GPA formula used to generate the target variable introduces some design bias into model behaviour
- No authentication layer — the app is designed for local/internal use only
- The explanation text is rule-based, not a true SHAP/LIME explanation
